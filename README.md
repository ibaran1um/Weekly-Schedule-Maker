# 週間スケジュール画像メーカー（Weekly-Schedule-Maker）

https://ibaran1um.github.io/Weekly-Schedule-Maker/

1週間の配信予定を入力するだけで、告知用のスケジュール画像（PNG）を作れるブラウザツールです。

- レイアウトは「カード」と「リスト」の2種類
- 画像サイズは 16:9・1:1・4:5・9:16 から選択
- 配色プリセット6種類と、色の細かい調整
- 立ち絵・背景画像の配置、手元のフォントファイルの使用
- 入力内容はブラウザに自動保存。翌週は「次の週」を押して、変わったところだけ直せば完成

**入力内容や画像はブラウザの中だけで処理され、外部には送信されません。** サーバー・データベース・ログインは使っておらず、外部のライブラリやフォントも読み込みません。

## 使い方

1. 「基本」で見出し・名前・週の始まりの日を入れます。
2. 「予定」で各日の時間・内容・タグを入れます。1日に3枠まで追加でき、配信しない日は「おやすみ」にチェックします。
3. 「見た目」でレイアウト・画像サイズ・配色などを選びます。右側（スマホでは上）のプレビューにすぐ反映されます。
4. 「PNGで保存」で画像を保存します。対応しているブラウザでは「画像をコピー」でクリップボードにも入れられます。

翌週は「次の週」を押すと日付だけが1週間進み、予定は残ります。予定をまっさらにしたいときは「予定をすべて消す」を使います。

## 保存について

- 文字と設定は、このブラウザの localStorage に自動で保存されます（使えない環境では保存されないだけで、動作には影響しません）。
- 立ち絵・背景画像・読み込んだフォントは保存されません。ページを開き直したら選び直してください。
- 「設定をファイルに保存」で JSON ファイルに書き出し、別のパソコンやブラウザで「設定ファイルを読み込む」から復元できます。

## フォントについて

標準では、パソコンに入っているゴシック体・明朝体を使います（端末によって見た目が変わります）。好きなフォントを使いたいときは「フォントファイルを読み込む」から .ttf / .otf / .woff / .woff2 を選んでください。ファイルはブラウザ内で使うだけで、アップロードはされません。

作った画像を公開・配布するときのフォントの利用条件はフォントごとに異なるので、各フォントのライセンスを確認してください。

## 読みやすさについて

「色を細かく調整」の中に、文字と枠のコントラスト比（WCAG 2.x の計算方法）を表示しています。4.5 未満になると警告が出ます。この値は背景のグラデーション色をもとに計算しているため、背景画像を使うときは「暗くする」や「枠の濃さ」で見ながら調整してください。

## 公開方法（GitHub Pages）

このリポジトリのファイルをそのまま置き、Settings → Pages で公開元のブランチ（ルート）を指定すれば動きます。ビルドは不要です。
